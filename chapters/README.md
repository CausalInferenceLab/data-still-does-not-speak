# 챕터 오너 안내

챕터 오너는 핵심 개념·실행 코드·잠정 해석과 **러너가 준비할 자료**를 주차 노트로 안내합니다. [챕터 노트 템플릿](../templates/chapter-notes.md)을 복사해 `chapters/w03/README.md`처럼 해당 주차에 작성하세요. 경로의 주차는 실제 담당 주차로 바꿉니다.

## 주차 노트 사용하기

1. [주차별 준비 자료 표](../assignments/README.md)에서 연습문제 또는 사례인지 확인합니다.
2. 문제 번호 또는 사례 출처를 구체적으로 지정하고 접근 방법·실행 조건·정리 질문을 안내합니다. 아직 정하지 못한 항목은 미정으로 표시하고, 정해지면 같은 노트를 업데이트합니다.
3. 핵심 개념, 자신이 확인한 결과와 잠정 해석, 아직 확인하지 못한 부분을 정리합니다.
4. [제출 안내](../CONTRIBUTING.md)에 따라 PR을 열어 공유하고, 모임에서 나온 검토 내용과 남은 질문을 같은 노트에 반영합니다.

러너는 이 노트에서 지정한 자료를 다룬 뒤 자신의 풀이·검토와 세 구간 기록을 [과제 경로](../assignments/README.md)에 제출합니다. 챕터 노트가 러너 개인의 제출물을 대신하지는 않습니다.

발표 슬라이드가 필요하면 [슬라이드 안내](../SLIDES.md)와 [덱 템플릿](../templates/deck.md)을 사용해 `slides/w03-ch03/index.md`처럼 작성합니다. 슬라이드는 선택이며, 실제 파일이 생긴 뒤 주차 노트에서 상대 경로로 연결하세요.

교재의 핵심은 자신의 말로 요약하고 문제 번호·출처를 남기세요. 허가 없이 교재 원문·스크린샷을 재배포하거나 개인정보·비밀 API 키·비공개 고객·회사 데이터를 공개하지 않습니다. 코드·자료를 공유할 때는 출처와 접근·배포 조건도 확인합니다.
