# 러너 과제 안내

러너는 해당 챕터를 읽고 **주차에 지정된 연습문제 풀이 또는 사례 검토와 세 구간 기록을 함께** 제출합니다. [러너 기록 템플릿](../templates/runner-record.md)을 복사해 시작하세요.

## 주차별 준비 자료

| 주차 | 읽을 챕터 · 활동 | 준비 자료 종류 |
| --- | --- | --- |
| W01 | OT | 정규 과제 지정 없음 |
| W02 | Ch1–2 · 빌더 시범 | 사례 |
| W03 | Ch3 | 연습문제 |
| W04 | Ch4 | 연습문제 |
| W05 | Ch5 | 사례 |
| W06 | 매지컬 위크 ① 네트워킹 | 사전 과제·제출물 없음 |
| W07 | Ch6 | 연습문제 |
| W08 | Ch7 | 사례 |
| W09 | Ch8 | 연습문제 |
| W10 | Ch9 | 연습문제 |
| W11 | Ch10 | 연습문제 |
| W12 | Ch11 | 연습문제 |

| W14 | 매지컬 위크 ② 해커톤 · 회고 | 정규 과제 지정 없음 |

이 표는 준비 자료의 **종류**를 안내합니다. 구체적인 문제 번호, 사례 출처·접근 방법, 실행 조건은 챕터 오너가 주차 노트에 안내합니다. 지정이 아직 없다면 오너에게 확인하며, 임의로 문제나 사례를 골라 지정 과제로 제출하지 않습니다. W01·W14의 표기는 정규 과제가 지정되지 않았다는 뜻이며, 그 주차의 다른 활동이나 제출 여부는 별도 안내를 확인하세요.

## 기록과 제출

1. [챕터 안내](../chapters/README.md)를 따라 해당 주차 노트에서 준비 자료를 확인합니다. 예: `chapters/w03/README.md`.
2. 챕터를 읽고 지정된 연습문제를 풀거나 사례를 검토합니다. 문제 번호·출처와 자신의 풀이·검토를 적습니다.
3. 아래 세 구간으로 생각의 흐름을 기록합니다. 실제 확인한 근거와 아직 확인하지 못한 부분을 구분합니다.
4. `assignments/w03/<github-id>/README.md`처럼 자신의 주차 폴더에 저장하고, [제출 안내](../CONTRIBUTING.md)에 따라 원본 저장소 `main`을 대상으로 PR을 엽니다. 처음이라면 [AI 튜터 안내](../TUTOR.md)를 사용하세요.

| 구간 | 기록할 질문 |
| --- | --- |
| 다룬 장면 | 어떤 데이터·분석·질문을 살폈는가? |
| 처음 생각과 검토 | 처음에는 어떻게 생각했고, 어떤 근거를 살폈는가? |
| 현재 판단 | 지금 어디까지 말할 수 있고, 무엇을 더 확인할까? |

코드가 있다면 자신의 주차 폴더에 함께 두고 기록에서 상대 경로로 연결할 수 있습니다. 실행 조건과 데이터 출처도 설명하세요.

**과제 PR을 열면 제출 완료입니다.** 리뷰·수정·병합과 Pages 반영은 별도입니다. GitHub ID와 작성 내용은 공개되므로 개인정보·비밀 API 키·비공개 고객·회사 데이터를 넣지 마세요. 허가 없이 교재 원문·스크린샷을 재배포하지 않고 문제 번호·출처와 자신의 풀이를 남깁니다.
