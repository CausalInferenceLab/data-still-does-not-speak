OT 자료 사용 안내

공개 자료는 읽기 전용입니다. 수정 제안은 GitHub 원본에 남기고, 검토 후 반영합니다.

슬라이드 보기

OT 열기에서 하단의 이전·다음 버튼으로 이동하세요. 키보드 방향키·Page Up·Page Down도 사용할 수 있습니다. Home은 첫 장, End는 마지막 장입니다.

파일로 보관하기

OT PDF 저장을 누르세요. 브라우저에서 PDF가 열리면 PDF 화면의 다운로드 버튼으로 저장할 수 있습니다. 작은 화면에서는 PDF를 확대해 읽으세요.

HTML을 파일로 보관하려면 OT 화면에서 브라우저의 페이지 다른 이름으로 저장을 선택하고 웹페이지, 전체 형식으로 저장하세요. 생성된 HTML과 이미지 폴더를 함께 보관해야 식당 사진도 표시됩니다.

GitHub에서 내용 확인·수정하기

  1. OT 원본 index.md를 엽니다. GitHub에서는 내용을 문서로 읽고, 발표 화면은 Pages에서 봅니다.
  2. 저장소를 Fork한 뒤 본인 사본에서 작업 브랜치를 만듭니다. 기존 포크가 있으면 사용하세요.
  3. slides/ot-live/index.md의 연필 아이콘으로 수정하고 Commit changes로 작업 브랜치에 저장합니다. 맨 위 설정과 슬라이드 구분선 ---은 유지하세요.
  4. Contribute → Open pull request로 변경을 제안합니다. 대상은 원본 저장소의 main입니다. 단계별 제출 안내도 참고하세요.

PR이 검토·병합되고 배포가 완료되면 Pages에 반영됩니다. PR을 여는 즉시 공개 자료가 바뀌지는 않습니다. 생성된 HTML·PDF를 직접 수정하거나 커밋하지 않습니다.
